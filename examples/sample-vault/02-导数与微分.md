# 导数与微分

## 定义

$$f'(x_0)=\lim_{h\to 0}\frac{f(x_0+h)-f(x_0)}{h} \tag{1}$$

上式的 \tag{1} 在 GitHub 上不会渲染——MathJax 没有公式编号支持。

## 常用求导

| 函数 | 导数 |
|------|------|
| $x^n$ | $nx^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\ln|x|$ | $\frac1x$ |

求导法则的证明要用到 [[01-极限与连续]] 里的夹逼定理。

```python
# 代码块里的 [[双链]] 不该被转换
def derivative(f, x, h=1e-6):
    return (f(x + h) - f(x)) / h
```
